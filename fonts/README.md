# Custom note fonts

Drop the font files here to activate them (woff2 preferred; woff/ttf/otf also work).
File names must match exactly:

- Home sticky note  → `another-shabby.woff2`   (Another Shabby)
- Work sticky notes → `biro-script-plus.woff2` (Biro Script Plus)

Until a file is present, the site falls back to the Caveat hand font.
